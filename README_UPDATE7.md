# 이번 업데이트에서 추가/수정된 6가지

이전 배포(v6, bbiyagbbiyag.onrender.com에 올라가 있는 버전) 이후로 아래 6가지를 전부 반영했습니다.
**아직 재배포는 하지 않은 상태**이니, 아래 "재배포 방법"대로 한 번만 다시 올리면 전부 적용됩니다.

## 1. 등록된 시간대만 표시
- 첫 화면/복약체크/기록 화면에 **약이 등록된 시간대만** 보여요.
- 약 추가·삭제 시 자동으로 표시되는 시간대가 바뀌어요.
- 약이 없는 시간대는 알림도 가지 않고, 복약 이행률·복약 패턴 분석에서도 아예 제외돼요(= 놓침으로 계산되지 않음).
- 관련 파일: `public/app.js`(`activeSlots()` 함수가 핵심), `server.js`(서버도 등록된 시간대에만 알림을 보내도록 동기화)

## 2. 기록 화면 월간 달력 수정
- 가로로 스크롤되던 날짜 목록을, **일~토 요일에 맞춰 정렬된 진짜 격자형 달력**으로 다시 만들었어요.
- ‹ › 로 이전/다음 달 이동, "오늘" 버튼으로 바로 복귀.
- 날짜에 그날 기록 개수만큼 작은 점 표시, 날짜 클릭 시 아래에 상세 기록 표시.
- 기존 복약 기록 데이터(localStorage)는 그대로 사용 — 구조 변경 없음.

## 3. 약 추가/수정 시 시간대 선택 버튼
- 기존엔 체크박스를 눌러도 선택됐는지 화면에 표시가 안 되는 버그가 있었어요(숨겨진 체크박스라 시각적 반응이 없었음) → 진짜 버튼처럼 누르면 바로 색이 바뀌도록 수정.
- **약 수정 기능**을 새로 추가했어요(기존엔 삭제만 가능했어요). 각 약 옆에 "수정" 버튼 → 이름/시간대/처방정보 수정 가능.

## 4. 복용함 / 건너뜀 / 나중에 + 2시간 자동 종료
- 복약 시간이 되면 알림에 3가지 선택지가 뜨고(일부 환경), 복약체크 화면에도 동일한 3개 버튼이 항상 떠요.
- 아무 선택이 없으면 **2시간 후 자동으로 미복용 처리 + 알림 종료** (예전의 "계속 울리는 문제" 해결).
- ⚠️ **아이폰은 OS 자체적으로 알림에 버튼을 지원하지 않아요.** 그래서 아이폰에서도 확실히 쓸 수 있도록 복약체크 화면에 동일한 3버튼을 넣어뒀어요 — 알림을 탭해서 앱을 열면 거기서 선택하면 돼요.

## 5. 홈 화면 안내 문구 추가
- "아직 OO 약을 못 챙기셨어요" 같은 카드 아래에 작은 글씨로 **"복약 체크 화면으로 이동하기 →"** 안내를 추가해서, 눌렀을 때 어디로 가는지 미리 알 수 있게 했어요.

## 6. '오늘의 맞춤 건강 정보' 영역 삭제
- 홈 화면에서 해당 섹션 전체(제목/더보기/카드)를 제거했어요. 빈 공간 없이 아래 콘텐츠가 자연스럽게 올라왔어요.

---

## 재배포 방법 (기존과 동일한 절차)
1. 이 폴더 전체를 GitHub 저장소에 덮어쓰기(커밋)
2. Render 대시보드에서 **Manual Deploy**(또는 자동 배포 설정이면 그냥 기다리기)
3. 환경변수(VAPID 키 등)는 그대로 두면 돼요 — 이번 업데이트에서 바뀌지 않았어요
4. 배포 후 휴대폰에서 앱을 껐다 켜면(또는 새로고침) 새 버전이 적용돼요. 서비스워커 캐시 버전을 올려뒀기 때문에 자동으로 갱신됩니다.

## 참고
- 로컬 저장 데이터(기존 사용자의 약 목록, 복약 기록 등)는 이번 수정으로 구조가 바뀌지 않았으니 그대로 유지돼요.
- `data/subscriptions.json`(서버 쪽 구독 정보)은 Render 무료 플랜 특성상 재배포 시 초기화될 수 있어요 — 전에 안내드린 대로, 기존 사용자는 설정에서 "🔔 푸시 알림 받기"를 한 번 다시 눌러주면 됩니다.
