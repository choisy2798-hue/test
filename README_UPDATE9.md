# v9 업데이트 — 홈 요약 → 복약 상세 → 일·주·월·년 전환

## 화면 흐름
홈 "오늘의 복약 현황" 카드 → **복약 현황(상세)** → 일간·주간·월간·연간 전환
- 상세 화면은 탭 영역 안에 열려서 **하단 메뉴가 그대로 보여요.**
- 뒤로 가기: 화면 왼쪽 위 ‹ 버튼, 안드로이드 뒤로 가기 버튼 모두 원래 화면으로 돌아가요.
- 상세 화면에서 하단 메뉴를 누르면 상세 화면이 닫히고 그 탭으로 이동해요.

## 홈
- 맨 위: 페이지 제목 "복약 알리미" + 오늘 날짜·이름 (기존 인사 문구 자리)
- 반원 그래프 → **원형 링**(오늘 복용 N/M회, 다음 복약 시간). 시간대 칩은 그대로. 카드를 누르면 상세(일간)
- 가로 스크롤 숫자 3개 → **2열 카드**: 복약 이행률(이번 주 요일별 미니 막대 → 주간), 연속 복약(최근 7일 점 → 월간)
  + **처방약 소진 임박** 줄 카드(→ 복약 관리)
- 상태 안내, 미복용 알림, 응원, 식물 키우기, 약·알람 등록, 불편한 점 버튼은 그대로

## 복약 상세
- 제목 아래 기준 날짜/기간 표시, 그 아래 일간·주간·월간·연간 선택(기존 기록 탭의 둥근 선택 버튼 디자인 재사용)
- ‹ › 로 이전/다음 기간, "오늘로/이번 주로/이번 달로/올해로" 버튼. 미래로는 못 넘어가요.
- 일간: 링 + 시간대별 상태(약 이름, 놓친 이유) + "기록에서 이 날짜 수정하기"(→ 기존 기록 탭 달력, 해당 날짜 선택)
- 주간·월간·연간: 이행률 % + 막대 그래프(막대를 누르면 그날/그달로 이동) + 날짜별 요약 + 시간대별 복약 + 놓친 이유
- 기록 탭 "이번 주 복약 현황", 설정 "복약 관리 현황" 카드도 누르면 같은 상세 화면(주간)으로 이동

## 데이터
- 새로 저장하는 값 없음. 기존 `medicationRecords`(지난 날짜), 오늘 실시간 상태, `missReasons`만 읽어서 계산
- 기록이 없는 날·미래 날짜는 계산에서 빠지고 그래프에 빈 칸으로 표시 (임의 데이터 없음)
- 상세 화면의 이행률은 "복용 횟수 ÷ (복용+놓침) 횟수"로 계산
