# 실제 푸시 알림 적용 가이드

지금까지는 앱이 화면에 떠 있어야만 알림이 울렸어요. 이번 업데이트로 **앱을 완전히 꺼둬도 정해진 시간에 알림이 오도록** 서버를 추가했습니다.

## 무엇이 바뀌었나요
- `server.js` : 항상 켜져 있는 서버가 30초마다 시간을 확인해서, 등록된 각 기기에 복약 시간 알림을 직접 보내요 (Web Push).
- `public/app.js` / `public/sw.js` : 설정 > 복약 알림 설정 화면에 **"🔔 이 기기로 푸시 알림 받기"** 버튼이 생겼어요. 이 버튼을 한 번 누르면 서버에 구독 정보(알림 시각 등)를 등록해요.
- 복약 체크(✅)를 하면 서버에도 "오늘 이 시간대는 이미 챙겼다"고 알려줘서, 이미 복용한 시간대에는 반복 알림이 오지 않아요.
- 이제부터는 **웹사이트 형태(정적 파일)가 아니라 "서버 프로그램"**이라서, 배포 방법이 조금 달라졌어요 (Netlify Drop 같은 정적 호스팅은 더 이상 사용할 수 없고, Node 서버를 띄울 수 있는 곳이 필요해요).

## 배포 방법 (Render.com 무료 플랜 기준, 카드 등록 불필요)

1. https://render.com 가입 (GitHub 계정으로 가입하면 편해요)
2. 이 폴더 전체(server.js, package.json, public/ 등)를 GitHub 저장소에 업로드
3. Render 대시보드 > **New > Web Service** > 방금 만든 저장소 선택
4. 설정값
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. **Environment** 탭에서 아래 3개 환경변수를 `.env.example` 파일 내용 그대로 추가
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `VAPID_SUBJECT`
6. Deploy 버튼 클릭 → 몇 분 후 `https://앱이름.onrender.com` 같은 주소가 생성돼요
7. 이 주소를 어르신 휴대폰에서 열고 "홈 화면에 추가" (이전 가이드와 동일)

> 다른 선택지: Railway, Fly.io 도 비슷한 방식으로 무료로 Node 서버를 올릴 수 있어요.

## ⚠️ 무료 플랜의 중요한 한계 (꼭 읽어주세요)

**1. 파일 저장이 영구적이지 않을 수 있어요**
지금 구독 정보는 `data/subscriptions.json` 파일에 저장돼요. Render 무료 플랜은 서버를 재배포하거나 일정 시간 사용이 없으면 재시작되면서 **이 파일이 초기화될 수 있어요.** 즉, 어르신이 다시 "푸시 알림 받기" 버튼을 눌러야 할 수도 있어요.
- 한 달 테스트(소수 인원) 정도는 이 상태로도 크게 문제없지만, 안정적으로 가려면 Render의 "Persistent Disk"(유료) 또는 작은 무료 DB(Supabase 등)로 바꾸는 걸 다음 단계로 권장해요. 이 부분은 "다인용 구조" 작업 때 같이 정리하면 좋아요.

**2. 무료 플랜은 일정 시간 요청이 없으면 서버가 잠들어요(sleep)**
서버가 잠들어 있는 동안에는 30초 스케줄러도 멈춰서, 그 시간에 걸린 알림은 못 보내고 서버가 깨어난 뒤에야 다시 정상 작동해요. Render 무료 플랜은 보통 15분 무요청 시 슬립 모드로 들어가요.
- 완전히 해결하려면 유료 플랜(월 몇 천원대)으로 올리거나, 외부에서 5~10분마다 서버를 "깨워주는" 핑(ping) 서비스(예: UptimeRobot, 무료)를 걸어두는 방법이 있어요. **한 달 실사용 테스트라면 UptimeRobot으로 5분마다 `/api/health` 주소를 핑 해두는 걸 강력히 추천해요.**

**3. 아이폰 제약**
- iOS 16.4 이상이어야 하고, 반드시 **홈 화면에 추가된 상태(Safari 탭에서 그냥 열어둔 상태 X)**에서만 푸시 알림이 와요.
- 홈 화면에 추가한 뒤 앱을 열어서 "🔔 이 기기로 푸시 알림 받기" 버튼을 한 번 눌러야 알림이 시작돼요.

## 로컬에서 테스트하는 방법
```
npm install
cp .env.example .env
npm start
```
브라우저로 `http://localhost:3000` 접속 (단, 실제 폰에서 테스트하려면 HTTPS가 필요해서 위 배포 과정을 거쳐야 해요 — localhost는 개발 확인용이에요).
