# v8 업데이트 — 어르신이 더 쉽게 쓰도록

## 바뀐 점
1. **마이페이지 → 설정** (아래 탭, 맨 위 제목, 왼쪽 메뉴, 안내 문구 모두. 아이콘 ⚙️)
2. 홈 맨 아래에 큰 **💊 약·알람 등록하기** 버튼 (누르면 복약 정보 관리 화면)
3. 홈에 **📋 최근 복약 기록** (최근 5일, "완료 N/전체 N") + **전체 기록 보기** 버튼 (→ 기록 탭 달력)
4. 홈 맨 위 문구가 **"10월 9일 아침 약 드실 시간이에요"** 처럼 날짜+시간대로 나와요. 알림 이름을 바꿨으면 그 이름 사용(예: "아침 혈압약")
5. **😣 약 먹고 불편한 점이 있으셨나요?** 버튼 → 어지러움/속쓰림/메스꺼움/졸림/두통/가려움·발진/기타(직접 입력 100자). 기록 탭 날짜를 누르면 그날 기록이 보이고 삭제할 수 있어요. "심하거나 걱정되면 병원·약사님께 상담하세요" 문구 포함.
6. 설정 > **📖 앱 사용 방법**: 카드 6장이 한 페이지에 쭉 나와요. 처음 앱을 열면 "사용 방법 보기 / 다음에 볼게요" 창이 딱 한 번 떠요.

## 수정한 파일
`public/index.html`, `public/app.js`, `public/sw.js`(캐시 버전 v4→v5), README들(마이페이지→설정 단어만)

## 새로 저장되는 값 (기존 구조는 그대로, 추가만)
- `sideEffects` : 불편한 점 기록 목록 (appData 안에 따로)
- `manualSeen` : 사용 방법 안내를 이미 봤는지 (true/false)
- 전체 데이터 삭제 시 둘 다 같이 지워져요.

## 재배포
기존과 같이 GitHub에 올리고 Render 재배포. 폰에서는 앱을 한 번 완전히 닫았다 열면 새 버전이 적용돼요.

## 추가 수정 (복약 체크·기록·건강정보·설정)
- **수정함**
  - 복약 체크: 약마다 따로 체크(약이 2개 이상이면 "1/2 복용" 표시). 그 시간대 약을 모두 체크하면 자동으로 "복약 완료". "복용함/확인 완료" 버튼은 남은 약을 한 번에 체크. 약별 상태는 기록 탭 날짜 상세에도 표시됨. 새 저장 값: `medChecks` (기존 기록 구조는 그대로)
  - 기록 > 일정: "복약 알림 설정", "복약 시간 안내" 삭제
  - 기록 > 달력 화면의 "최근 기록" 영역 삭제 (달력·기록 데이터는 그대로)
  - 건강정보: "복약 순응도 높이는 5가지 습관" 실제 내용 추가 (예전엔 "준비 중" 링크만 있었음)
  - 설정: "복약 알림 설정"+"복약 정보 관리" → **"복약 관리"** 한 메뉴로 통합(약 등록·수정 + 알림·시간 설정 모두 한 화면)
  - 설정: 앱 정보(상단 버튼과 화면) 삭제
- **이미 되어 있어 건너뜀**: 없음 (위 항목 모두 실제로 남아 있었음)
- 캐시 버전 v6 → v7
- 약 목록에서 '수정' 버튼이 너무 넓어 글자가 세로로 깨지던 문제 수정 (캐시 v8)
- 복약 체크: 약을 눌러도 바로 완료되지 않고, 아래 '복약 완료' 버튼을 눌러야 완료 (캐시 v9)
- 복약 체크(재수정): 약을 눌러 "선택" → 하단 **"선택한 약 N개 복용 완료"** 버튼으로 선택한 약만 기록. 일부만 먹어도 버튼 활성화, 안 고른 약은 "미확인"으로 남고 나중에 다시 체크 가능. 선택 없으면 "먹은 약을 체크해 주세요"(비활성). 모든 약이 확정되면 그 시간대가 "복약 완료". (캐시 v10)
- 복용 완료/취소(재수정): 아침·점심·저녁·취침전 모두 복용 완료 가능(시간이 지났거나 건너뛴 시간대도 늦게라도 완료 가능). 복용 완료한 약은 "완료 취소" 버튼, 시간대 전체 완료 시 "복용 완료 취소" 버튼. 기록 탭에서 지난 날짜도 약별로 "복용 완료/완료 취소" 가능(해당 날짜만 변경). (캐시 v11)
- 미복용 알림(재수정): 복용 시간이 지났는데(2시간 안) 선택이 없는 시간대마다 홈·복약체크 화면에 "약 드실 시간이 지났어요" 카드 + 복용함/건너뜀/나중에 버튼 표시. 아침·점심·저녁·취침전 공통 로직, 시간대별 독립 처리. 앱을 늦게 열어도 상태 기준으로 표시. (캐시 v12)
- 긴급 수정(복약체크): 복용 시간이 지난 직후(2시간 안)에도 아침·점심·저녁·취침전 모두 '미복약' 표시 + 약별 선택 + "선택한 약 N개 복용 완료" 버튼이 항상 보이도록 통일. 복용함/건너뜀/나중에 선택지는 그 위에 추가로 표시. (캐시 v13)
- 홈 '오늘의 복약 현황'에서 "N/N회 완료" 문구 삭제 ('다음 복약 시간'은 유지, 계산 기능은 그대로) (캐시 v14)

- 건강정보 탭·추천 콘텐츠·5가지 습관 삭제 (아래 메뉴 4개: 홈/복약체크/기록/설정, 왼쪽 메뉴에서도 제거)

- "오늘도 함께 챙겨봐요!"를 이번 주 이행률·연속 복약·소진 임박 바로 아래로 이동
- 캐시 v15

## 앱 이름·아이콘 (복약 알리미)
- 이름을 "복약 알리미"로 통일: 브라우저 탭 제목, 앱 상단·왼쪽 메뉴, 알림 제목, manifest name/short_name, iOS 홈 화면 이름(apple-mobile-web-app-title), 서버 푸시 제목
- 아이콘: 둥근 정사각형 초록 배경 + 흰/노랑 캡슐 (`icon-192/512.png` 둥근 모서리, `icon-maskable-512.png`·`icon-180.png`는 모서리 없는 전체 배경 - 안드로이드/아이폰이 알아서 둥글게 처리, `favicon-32.png`)
- 이미 설치한 폰은 이름·아이콘이 자동으로 안 바뀌어요. 홈 화면 아이콘을 삭제하고 다시 "홈 화면에 추가"하세요. (캐시 v16)
